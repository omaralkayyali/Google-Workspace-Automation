## <img src="https://fonts.gstatic.com/s/e/notoemoji/latest/1f4d6/512.webp" width="25" height="25"> About the Repository / عن المستودع

### [English]
Welcome to the enterprise-grade centralized portfolio for workflow cloud automation, advanced serverless routing pipelines, and robust **Google Apps Script (GAS)** ecosystems. This architecture transforms manual entry streams from Google Forms and Sheets into automated data structures, reducing corporate processing times to absolute zero.

### [العربية]
مرحباً بك في المنظومة البرمجية المتكاملة والمركزية المخصصة لأتمتة مسارات العمل وهندسة البيانات السحابية عبر حلول **Google Apps Script (GAS)**. تم تصميم هذا المستودع ليقوم بتحويل المدخلات العشوائية من النماذج والجداول الإلكترونية إلى قواعد وهياكل بيانات مؤتمتة ومترابطة كلياً دون أي تدخل بشري.

## <img src="https://fonts.gstatic.com/s/e/notoemoji/latest/1f4c1/512.webp" width="25" height="25"> Active Production Modules / المشاريع المتاحة والنشطة بالتفصيل

### 1️⃣ 📈 Module: `finance-automation` | نظام الأتمتة والعمليات المالية
* **Description (EN):** An automated pipeline tailored to eliminate human errors in accounts department. It manages multiple transactional sheets simultaneously, injecting independent mathematical tracking indices right upon form arrivals.
* **الوصف (AR):** منظومة برمجية متكاملة مصممة لإلغاء الأخطاء البشرية في المحاسبة والمطابقات. يقوم النظام بمعالجة النماذج المالية والتحقق منها وإدارتها عبر آليات ترقيم مستقلة وحوسبة النقل الفوري للأوراق الخارجية.
* **✨ Key Logic Includes / أهم الميزات البرمجية المطورة:**
  * **سند الصرف (Payment Voucher):** Tracks columns dynamic shifts and generates strict $6800+$ sequence indexations.
  * **سند القبض (Receipt Voucher):** Routes dynamic metadata parameters and builds custom monthly logs (`دخل يناير`, `دخل فبراير`) into localized master external sheets.
  * **طلب الصرف (Disbursement Request):** Integrates standalone internal workflows and logs approval indexes starting from $1$.

---

### 2️⃣ 🎬 Module: `Media-Workflow-Sorter` | نظام فرز وجدولة الميديا والإنتاج
* **Description (EN):** A cloud storage optimization microservice built on top of **Google Drive API** to parse, track, and categorize heavy creative media resources, folder structures, and customer design assets dynamically.
* **الوصف (AR):** خدمة سحابية مصغرة مبنية بالاعتماد على واجهات برمجية متقدمة لـ Google Drive، تعمل على فحص وترتيب وتصنيف موارد الميديا والإنتاج الفني الضخمة وملفات التصاميم وتوزيعها في مجلدات ذكية وممنهجة تلقائياً.
* **✨ Key Logic Includes / أهم الميزات البرمجية المطورة:**
  * Automated cloud directory validation and building structure loops.
  * Instant tracking and generation logs for incoming team or client uploads.

## <img src="https://fonts.gstatic.com/s/e/notoemoji/latest/1f511/512.webp" width="25" height="25"> System Architecture Philosophy / فلسفة بناء المشاريع

* **Decoupled Logic (هندسة برمجية مستقلة):** Each subdirectory operates as a standalone microservice containing localized core scripts, separate environment logic, and isolated user configuration loops.
* **Environment Abstraction (أمن الخصوصية والبيانات):** All internal `Spreadsheet IDs`, database indices, and target root directory tokens are replaced with public-safe string variables (`"YOUR_ID_HERE"`).
